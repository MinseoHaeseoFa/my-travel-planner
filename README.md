# 🧭 여행 플래너 · 오프라인 여행 지갑

모바일(390px) 최우선으로 만든 **7탭 범용 여행 플래너**입니다. 일정·티켓·준비물·예산·맛집·정보를 한 앱에서 관리하고, 비행기 모드에서도 열리며, PC와 모바일은 구글 시트로 동기화할 수 있습니다.

- 라이브 구조: `index.html` + `styles.css` + `app.js` (빌드 없음, 순수 정적 파일)
- 저장: 브라우저 `localStorage` (기기 안에서 완결)
- 배포: GitHub Pages / Vercel / Netlify 등 정적 호스팅 아무 곳이나 가능
- 상단 **🏠 나의 여행 지도 홈** 버튼: 허브 포털(`https://my-travel-map-kohl.vercel.app/`)로 **같은 탭에서** 이동(새 탭 없음)

## 바로 쓰기

```bash
python3 -m http.server 8000
# http://localhost:8000
```

`file://`로 열어도 화면은 뜨지만, Service Worker(PWA 오프라인 캐시)는 `http(s)`에서만 동작합니다.

## 7개 탭

| 탭 | 내용 |
| --- | --- |
| 전체 | 여행 요약(D-day), 다음 일정, 출발·귀환 요약, DAY 한눈에 보기, `[✨ 동선 추천 채우기]` |
| 일정 | DAY 스트립 + 도시 뱃지 + 시간 세로선 타임라인, 항목 추가·수정·삭제, **+1시간 순연**, `[🗺️ 동선 보기]`, `[🚆 도시·국가 이동]`, `[✨ 동선 추천]` |
| 티켓 | 항공 E-티켓 · 렌터카 · 숙소 바우처 · 패스, `[🎫 원본 보기]` 모달, 사진 업로드(Canvas 압축 → base64) |
| 준비 | 카테고리별 체크리스트, 진행률 바(`완료 / 전체`), 항목 추가·수정·삭제 |
| 예산 | 통화별 지출 입력, 통화별 합계 + 원화 환산 총액(참고 환율 수정 가능) |
| 맛집 | 장소명 · 종류 · 메모 · 영업시간 + 지도 직결 |
| 정보 | **숙소 비교 · 선택**(박별 배정 → 체크인·체크아웃 자동 일정), 국가별 긴급 연락처 자동 안내, 여행 메모(자동 저장) |

## 숙소 비교 · 선택 → 체크인·체크아웃 일정 자동 반영

`정보` 탭 맨 위 **숙소 비교 · 선택** 패널에서 숙소를 고르면 `일정` 탭에 체크인·체크아웃 카드가 자동으로 들어갑니다.

- **[✨ 추천 숙소]**: 여행 도시의 큐레이션 DB 추천 숙소(도시당 4곳)를 한 번에 후보로 담습니다. `동선 추천`으로 일정을 채웠다면 그 숙소들이 이미 후보에 있습니다.
- **후보 비교 카드**: 숙소명 · 도시/권역 · 특징·가격대 · 주소 · 전화 · 지도(네이버/구글 자동)를 나란히 보고, 카드 안의 **DAY 1 / DAY 2 …** 버튼으로 그 밤의 숙소를 바로 지정합니다(다시 누르면 해제).
- **박별 숙소 배정**: `DAY n 밤`마다 드롭다운으로 숙소를 고릅니다. 그날 도시의 숙소가 먼저 나옵니다.
- **전 일정 같은 숙소**: 한 번에 모든 박을 같은 숙소로 맞춥니다. 여러 날 + 도시가 바뀌는 여행은 박별로 다른 숙소를 지정하면 됩니다.
- **체크인 · 체크아웃 일정**: 연속된 같은 숙소는 하나의 구간으로 합쳐지고, 구간마다 **체크인 날짜/시간(기본 15:00)** 과 **체크아웃 날짜/시간(기본 11:00)** 을 고칠 수 있습니다. 숙소별 기본 체크인·체크아웃 시각은 [+ 숙소]·[수정]에서 정합니다.
- **일정 자동 반영**: 저장 즉시 `일정` 탭의 해당 DAY에 `🛏 숙박` 카테고리로 체크인·체크아웃 카드가 생기고 시간순으로 정렬됩니다. 같은 숙소로 바꾸거나 시간을 고치면 **중복 없이 교체**됩니다.
  - 카드에는 숙소명·주소 메모·지도 링크가 함께 들어갑니다.
  - 카드에서 시간을 고치면 숙소 계획에도 그대로 반영되고, 카드를 삭제하면 그 항목만 잠시 빼 두며 숙소 계획에서 **[체크인/체크아웃 다시 넣기]** 로 복원할 수 있습니다.
  - 숙소를 삭제하면 그 숙소로 잡은 구간과 자동 일정도 함께 정리됩니다.
  - 여행 기간을 줄이면 여행 범위를 벗어난 구간은 자동으로 정리됩니다.

## 출발·귀환 교통과 구간 이동

- `+ 새 여행` / `여행 정보 수정` 모달 아래 **[🚆 출발 · 귀환 교통 설정]**
  - 첫날 출발: 출발지(서울역·인천공항·자택 등) → 도착지(첫 도시 자동), 교통수단(항공/KTX·기차/자차/고속버스/선박), 출발·도착 시각
  - 마지막 날 귀환: 출발지(마지막 도시 자동) → 도착지, 교통수단, 출발·도착 시각
  - 저장하면 **DAY 1 첫 일정 / 마지막 DAY 마지막 일정**에 `이동` 카드가 자동 생성되고, 여행 정보를 다시 고치면 중복 없이 갱신됩니다. 출발지·도착지마다 지도가 따로 열립니다(대한민국 → 네이버 / 그 외 → 구글).
- `일정` 탭 **[🚆 도시·국가 이동]** — 어느 DAY, 출발 국가·도시, 도착 국가·도시, 교통수단(항공·신칸센·KTX·렌터카·버스·페리 등), 출발·도착 시간, 터미널/역 메모를 입력하면 구간 이동 카드가 타임라인에 등록됩니다. 카드에서 바로 수정·삭제할 수 있습니다.

## 동선 추천 (큐레이션 마스터 DB)

`일정`·`전체` 탭의 **[✨ 동선 추천]** 을 누르면 여행 도시별로 랜드마크·체험 / 맛집 / 카페 / 숙박 권역을 동선 순서(오전 → 점심 → 오후 → 카페 → 저녁)로 보여 줍니다.

- 모두 선택 / 모두 해제 / 카테고리 전체 / 개별 체크로 고른 뒤 **[선택 항목으로 일정·맛집·숙소 채우기]**
  - 랜드마크·체험 → 각 DAY의 오전·오후 시간대에 자동 배치 (첫날 출발·마지막 날 귀환 이동과 겹치지 않게 비켜서 배치)
  - 맛집·카페 → `일정` 식사·카페 슬롯 + `맛집` 탭에 동시 등록
  - 숙박 → `정보` 탭 숙소 카드 + 체크인 15:00 / 체크아웃 11:00 메모 자동 반영
- 채운 항목은 기존과 같이 `[✏️ 수정]`으로 시간·장소명·메모·국가/도시를 고치거나 삭제할 수 있습니다.
- 수록 도시: 국내 12곳(서울·부산·경주·제주·강릉·속초·여수·전주·수원·안동·포항·춘천) + 해외 20곳(도쿄·교토·오사카·후쿠오카·삿포로·오키나와·타이베이·가오슝·홍콩·다낭·호이안·나트랑·방콕·치앙마이·싱가포르·파리·런던·로마·바르셀로나·뉴욕).
- DB에 없는 소도시는 오전 명소·점심·오후 명소·카페·저녁·숙소 **자리표시자**로 기본 골격을 만들고, 실제 장소명으로 수정하도록 안내합니다. 상호를 지어내지 않습니다.

하단 플로팅 `[◀ 이전 / 다음 ▶]` 바에 현재 탭과 `1 / 7` 페이지 표시가 있습니다.

## 동선 보기 (팝업 지도 · Leaflet + OpenStreetMap)

`일정` 탭 상단 **[🗺️ 동선 보기]** 를 누르면 일정의 이동 동선을 팝업 지도로 한눈에 봅니다.

- **엔진**: Leaflet 1.9.4(CDN, jsDelivr → unpkg 폴백) + OpenStreetMap 타일. 모달이 열릴 때 `invalidateSize()`를 호출해 타일이 잘리거나 회색으로 남지 않습니다. CDN을 못 불러오면(오프라인) 지도 대신 안내 문구를 띄우고 목록은 그대로 씁니다.
- **전체 / DAY 전환**: 모달 상단 칩으로 기본은 현재 선택된 DAY, `전체`를 누르면 DAY별 색으로 전환합니다.
- **순서 마커**: 일정 순서대로 `1, 2, 3…` 번호 원형 마커 + 순서대로 잇는 선과 방향 화살표(전체 보기에서는 DAY별 색 구분).
- **마커 팝업**: 순서·시간·장소명·이전 장소와의 직선거리(km)·예상 이동시간(분)·기존 `mapInfo` 기준 네이버 지도/구글 맵 링크.
- **좌표 보완**: 일정의 `lat`/`lon`을 먼저 쓰고, 없으면 Nominatim에 `장소, 도시, 국가`로 조회합니다(초당 1회 순차 조회, 별도 캐시 `mtp.geo.v1`에만 저장 — 여행 데이터는 바꾸지 않음). 못 찾은 항목은 모달 안 **위치 미확인** 목록으로 정직하게 안내합니다(같은 이름의 다른 장소를 찍지 않도록 장소명만으로 재조회하지 않습니다).
- **순서 목록**: 모달 하단 목록을 누르면 지도가 그 마커로 이동하며 팝업을 엽니다.

## 국내 vs 해외 지도 자동 분기

- 국가가 **대한민국** → `https://map.naver.com/p/search/{도시}%20{장소}` + `네이버 지도` 뱃지
- 그 외 국가 → `https://www.google.com/maps/search/?api=1&query={도시}%20{장소}` + `구글 맵` 뱃지
- 한 여행에 국내·해외가 섞여 있어도 **항목별 국가/도시**로 판단합니다. (일정 추가 모달의 `지도 국가`)

## 여행 만들기

`+ 새 여행` → **"어디로 떠나시나요?"** 모달에서 여행 제목, 기간(시작·종료), 국가, 도시(복수·순서 변경·삭제)를 입력하면 `DAY`가 자동 계산되고, 날짜별 일정 칸이 만들어집니다. 처음 열면 바로 체험할 수 있는 샘플 여행 2개가 들어 있습니다.

- `경주 · 부산 2박 3일` (대한민국)
- `도쿄 · 교토 3박 4일` (일본)

샘플은 여행 선택기에서 **한 번에 삭제**할 수 있고, 티켓에도 "샘플"이라고 표시되어 실제 예약과 섞이지 않습니다.

## 동기화 / 백업

상단 `[🔄 동기화 / 백업]`:

1. **JSON 내보내기 / 불러오기** — 티켓 사진까지 한 파일에 담깁니다.
2. **구글 시트 실시간 동기화(SSOT)** — `apps-script/Code.gs`를 스프레드시트에 붙여넣고 웹앱으로 배포한 뒤, 그 URL을 앱에 넣습니다.
   - `저장하기`: `Trips` 시트를 비우고 현재 여행 전체로 교체
   - `불러오기`: 시트 내용으로 이 기기 데이터를 교체(확인 후)
   - `1분마다 자동으로 불러오기` 옵션(기본 꺼짐)

## 오프라인

- `manifest.webmanifest` + `sw.js`로 앱 셸을 캐시합니다.
- 상단에 **온라인 / 오프라인** 상태 배지가 있습니다.
- 티켓 사진은 1400px·JPEG 0.82로 압축해 `localStorage`에 저장되므로, 비행기 모드에서도 모달로 원본을 열 수 있습니다.

## 알려진 한계

- 저장 공간은 브라우저 `localStorage`(보통 5MB)입니다. 사진이 많으면 앱이 안내 문구를 띄우니 JSON 백업 후 정리하세요.
- 구글 시트 동기화는 시트 셀당 50,000자 제한 때문에 45,000자씩 나눠 저장합니다. 사진을 아주 많이 넣으면 동기화가 느려질 수 있습니다.
- 서버가 없으므로 두 기기가 동시에 수정하면 마지막에 저장한 쪽이 이깁니다(SSOT 교체 방식).
- 긴급 연락처는 일반적으로 알려진 번호를 국가별로 안내합니다. 여행 전 현지 공식 안내로 한 번 더 확인하세요.
- **동선 보기 지도**는 온라인일 때만 그려집니다(Leaflet CDN + OSM 타일). 오프라인이면 좌표 조회·지도 없이 순서 목록과 '위치 미확인' 안내만 표시합니다. 장소명이 일반적이면(예: "호텔 체크인") 좌표를 못 찾아 '위치 미확인'에 남습니다.
- 지도 이동 시간은 기존 앱과 같은 계산식(도심 평균 20km/h + 대기)으로, 실제 교통 상황과 다를 수 있습니다. 구간 거리는 **직선거리**입니다.

## 파일 구조

```
index.html               화면 셸
styles.css               디자인 (모바일 최우선 + 1280px 반응형)
curation.js              동선 추천 마스터 DB (국내 12 · 해외 20개 도시)
app.js                   상태·렌더링·모달·동기화 전체
sw.js                    Service Worker (오프라인 캐시)
manifest.webmanifest     PWA 매니페스트
icons/                   앱 아이콘 (192 · 512 · maskable)
apps-script/Code.gs      구글 시트 SSOT 동기화 스크립트
```
